# Migrations

Database migrations belong here.

Guidelines:

- Keep migrations ordered and reviewable.
- Include rollback notes when the migration tool supports rollback.
- Document data migrations separately from schema-only migrations.
- Link migrations to the Plane task and PR that introduced them.

The migration tool is not finalized yet. When selected, document the command in the root `Makefile` and in `docs/infrastructure/project-architecture.md`.

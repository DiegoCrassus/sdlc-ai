# Infrastructure as Code — Terraform

This directory contains Terraform modules for provisioning the application infrastructure.

## Purpose

Reproducible, version-controlled infrastructure definitions for:
- **PostgreSQL** — primary database
- **Redis** — cache + rate limiting + job queue
- **Backend** — container service (FastAPI)
- **Frontend** — static/CDN hosting (Next.js)

## What belongs here

- Terraform `.tf` modules for each infrastructure component
- Environment-specific `.tfvars` files
- Provider configurations
- Outputs consumed by the application

## What does NOT belong here

- Application code
- Database migration files (those live in `app/backend/migrations/`)
- Docker Compose files (those live in `app/infra/docker-compose.yml`)
- Kubernetes manifests (separate directory if needed)
- Secrets or credentials (use environment variables)

## Expected structure

```
terraform/
├── main.tf                  ← provider config + backend
├── variables.tf             ← all configurable variables
├── outputs.tf               ← outputs for other modules
├── modules/
│   ├── database/            ← PostgreSQL
│   ├── cache/               ← Redis
│   ├── backend/             ← Container/compute service
│   └── frontend/            ← CDN/static hosting
└── environments/
    ├── local.tfvars         ← Docker provider for local dev
    └── staging.tfvars       ← staging environment variables
```

## Quick start

```bash
# Initialize (local, no remote backend)
terraform init -backend=false

# Validate syntax
terraform validate

# Plan for local environment
terraform plan -var-file=environments/local.tfvars

# Apply (local only — staging/prod requires approval)
terraform apply -var-file=environments/local.tfvars
```

# SDLC Doctor Adapter

YAML canônico: `.sdlc/agents/subagents/sdlc-doctor.yaml`

Use quando o usuário pedir saúde do sistema, maturidade SDLC, drift entre docs/specs/generated, prontidão de gates ou bloqueios humanos.

## No Cursor

- Leia o YAML canônico e a skill `.sdlc/skills/sdlc-doctor/`.
- Colete evidências antes de concluir.
- Não exponha valores de secrets; reporte apenas presença ou ausência.
- Entregue status, maturidade, findings e próximas ações.

## Exemplo

```text
Use o sdlc-doctor para diagnosticar o estado atual do sistema.
```

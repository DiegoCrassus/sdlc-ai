# Spec Author Adapter

YAML canônico: `.sdlc/agents/subagents/spec-author.yaml`

Use quando a tarefa tocar specs declarativas, contratos DSL, schemas de ficha, canvas, agentes de produto ou evals declarativos.

## No Cursor

- Leia o YAML canônico e a skill `.sdlc/skills/dsl-authoring/`.
- Produza diffs pequenos, tipados e legíveis em `specs/`.
- Não implemente lógica de runtime em specs.

## Exemplo

```text
Delegue ao spec-author a criação da spec declarativa para este novo contrato.
```

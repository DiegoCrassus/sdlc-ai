# Plane Integrator Adapter

YAML canônico: `.sdlc/agents/subagents/plane-integrator.yaml`

Use para work items, cycles, modules, Pages e espelhamento de intents do SDLC no Plane.

## No Cursor

- Leia o YAML canônico e a skill `.sdlc/skills/plane-sdlc/`.
- Use Plane MCP quando disponível.
- Nunca exponha `PLANE_API_KEY`.

## Exemplo

```text
Delegue ao plane-integrator a criação dos work items Plane para esta intent.
```

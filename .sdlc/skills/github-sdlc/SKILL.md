# GitHub SDLC

## Prerequisites

- GitHub MCP enabled (`.cursor/mcp.json`, token in `GITHUB_PERSONAL_ACCESS_TOKEN`)
- Optional: `gh auth login` for local scripts

## Mandatory order

1. Plane task exists and has a readable identifier (`RPG-N`).
2. Branch is created from `develop` with `feature/RPG-N` or `bugfix/RPG-N`.
3. Work is committed to that branch.
4. PR targets `develop`.
5. GitHub Actions run lint and unit tests.
6. Failed checks create/update an issue and hand off to `issue-resolution`.
7. Checks are re-run after the fix.
8. Human owner approval is required before merge into `develop`.

## SDLC ↔ GitHub mapping

| Phase | GitHub artifact | Label |
|-------|-----------------|-------|
| plane-ready | Plane task referenced in PR | — |
| implement | Branch + commits | `sdlc:implement` |
| review | Pull Request to `develop` | `sdlc:ready` |
| ci-fail | Issue generated by Actions | `sdlc:ci-fail` / `sdlc:lint-fail` |
| done | Merged PR into `develop` | close issue after evidence |

## MCP workflow (agent)

1. **Resolve Plane task** — retrieve or create `RPG-N` before any branch.
2. **Create branch** — `.sdlc/scripts/gh-branch-start.sh feature RPG-123` or `bugfix RPG-123`.
3. **Open PR** to `develop` with Plane ID, validation evidence, and issue links.
4. **Check Actions** — lint and unit tests must be green on the latest head SHA.
5. **On failure** — ensure issue exists, trigger/hand off to `issue-resolution`, and wait for re-run.
6. **Before merge** — require human owner approval; never merge just because checks are green.

## PR body template

```markdown
## Summary
- …

## SDLC
- [ ] Plane task linked (`RPG-N`)
- [ ] Branch follows `feature/RPG-N` or `bugfix/RPG-N`
- [ ] `make test`, `make lint`, and `make validate` green
- [ ] GitHub Actions green on latest head SHA
- [ ] Human owner approval before merge

## Issue
Closes #NN
```

## Do not

- Commit tokens or `.env`
- Force-push `main`
- Merge with failing required checks
- Merge into `develop` without human owner approval
- Start GitHub workflow without a Plane task

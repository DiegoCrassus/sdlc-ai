# Issue Resolution

## Workflow

1. Read the issue title, body, labels, linked run, PR, branch, and Plane card.
2. Reproduce or inspect the failure logs.
3. Move the related Plane card to `In Progress`.
4. Fix the smallest safe scope.
5. Validate locally when possible.
6. Push to the existing branch or open a fix branch/PR.
7. Comment evidence and close the issue only after checks pass.

## Required Evidence

- Root cause.
- Changed files or commit SHA.
- Validation commands.
- Actions URL after fix.
- Plane card transition.

## Guardrails

- Do not hide failures by weakening required checks.
- Do not close an issue without evidence.
- If the issue reveals missing process, add/update the relevant command or skill.
